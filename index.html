    Install as an app

    Installing gives it its own icon, opens it full screen and lets it work offline.

    iPhone and iPad
    1. Open this page in Safari.
    2. Tap Share (the square with an arrow). On iOS 26, tap ••• first, then Share.
    3. Scroll down and tap Add to Home Screen. Leave Open as Web App on, then tap Add.
    4. From now on, open it from the Home Screen icon. That copy keeps its own data, separate from Safari tabs, and Safari can clear data for websites you don't open often.
    Android
    1. Open this page in Chrome.
    2. Tap the ⋮ menu, then Add to Home screen and choose Install.
    3. Open it from the new icon.
    Windows
    1. Open this page in Edge or Chrome.
    2. Click the install icon at the right end of the address bar. If it isn't there: Edge ⋯ menu → Apps → Install this site as an app; Chrome ⋮ menu → Cast, save and share → Install page as app.
    3. It appears in the Start menu and can be pinned to the taskbar.
    Mac
    1. In Safari (macOS Sonoma or later): File → Add to Dock. Use the Dock app from then on; it keeps its own data, separate from Safari.
    2. Or in Chrome: click the install icon at the right end of the address bar.
