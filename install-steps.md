# How to install Vehicle Maintenance App

Link: **https://YOUR-USERNAME.github.io/vehicle-maintenance-app/**

It's free, has no account, and keeps your data on your own phone or computer. Install it so it has its own icon and works offline.

## iPhone or iPad

1. Open the link in **Safari**.
2. Tap **Share** (the square with an arrow). On iOS 26, tap **•••** first, then **Share**.
3. Scroll down, tap **Add to Home Screen**, leave **Open as Web App** on, and tap **Add**.
4. **Always open it from the Home Screen icon.** Safari can clear data for websites you don't open often, but the Home Screen app keeps its own. Anything you type into a Safari tab stays in that tab, so add it to the Home Screen before you start.

## Android

1. Open the link in **Chrome**.
2. Tap **⋮** (top right), then **Add to Home screen**, then **Install**.

## Windows

1. Open the link in **Edge** or **Chrome**.
2. Click the **install icon** at the right end of the address bar. If you don't see it: in Edge, **⋯ → Apps → Install this site as an app**; in Chrome, **⋮ → Cast, save and share → Install page as app**.

## Mac

- **Safari** (macOS Sonoma or later): **File → Add to Dock**, then use the Dock icon from then on.
- **Chrome**: click the install icon at the right end of the address bar.

## Keep a backup

Your records live only on the device you use. Every so often, open **Backup** and tap **Export CSV**, then save the file somewhere safe (Files, iCloud Drive, Google Drive, or email it to yourself). The app reminds you if it's been a while. To move to a new phone or computer, export on the old one and use **Import** on the new one.
